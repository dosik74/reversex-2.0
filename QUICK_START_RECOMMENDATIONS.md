# ⚡ Быстрый Старт: Система Рекомендаций

## Что это?

Новая страница `/recommendations` на вашем сайте, как TikTok но для рекомендаций о фильмах, сериалах и развлечениях.

## Как это работает?

```
Пользователь A                    Пользователь B
      ↓                                 ↓
   Создает пост          →        Видит в ленте
   (с фото/рисунком)     →        Лайкает пост
                          ←        Пишет комментарий
```

## 🚀 Что нужно сделать

### Шаг 1: Создать Storage Bucket (2 минуты)

1. Откройте Supabase Dashboard
2. Storage → "Create new bucket"
3. Назовите `recommendations`
4. Сделайте Public
5. Готово!

### Шаг 2: Запустить миграцию SQL (1 минута)

1. В Supabase Dashboard → SQL Editor
2. Откройте файл: `supabase/migrations/20260129_create_recommendations.sql`
3. Скопируйте весь текст
4. Вставьте в SQL Editor
5. Нажмите "Run"
6. Готово!

### Шаг 3: Готово! 🎉

Страница уже доступна по адресу:
```
http://yoursite.com/recommendations
```

## Как пользователи используют

### Создать рекомендацию:
```
1. Нажать "+ Новая рекомендация"
2. Написать заголовок: "Лучший фильм года"
3. Написать описание: "Классная история, отличные актеры..."
4. (Опционально) Загрузить фото/рисунок
5. Нажать "Поделиться"
```

### Ответить на рекомендацию:
```
1. Нажать "Ответить" на посте
2. Написать свой ответ
3. Нажать "Отправить"
```

### Лайкнуть:
```
1. Нажать иконку ❤️
2. Готово!
```

## 💾 Таблицы в Supabase

Автоматически создаются при запуске миграции:

| Таблица | Назначение |
|---------|-----------|
| `recommendations` | Основные посты |
| `recommendation_media` | Фото и рисунки |
| `recommendation_replies` | Комментарии |
| `recommendation_likes` | Лайки |

## 🔐 Защита

- Каждый может видеть все рекомендации
- Только автор может удалить свой пост
- Все данные защищены RLS политиками
- Файлы хранятся безопасно в Storage

## ❓ Часто задаваемые вопросы

**В: Где я найду эту страницу?**
О: В навигации есть кнопка "Recommendations" с иконкой лампочки

**В: Можно ли удалить свой пост?**
О: Да, нажмите три точки ⋮ в карточке поста

**В: Какие форматы файлов поддерживаются?**
О: Любые изображения (JPG, PNG, GIF, WebP и т.д.)

**В: Есть ли ограничение на размер файла?**
О: Да, максимум 50 МБ на файл (в Storage)

**В: Видят ли мои ответы только я?**
О: Нет, все видят все ответы

## 🐛 Если что-то не работает

1. Проверьте, что Storage bucket `recommendations` создан
2. Проверьте, что миграция SQL выполнена успешно
3. Откройте консоль браузера (F12) и посмотрите ошибки
4. Убедитесь, что вы авторизованы
