# 🧪 TESTING GUIDE: INFINITE SCROLL & FILTERS

## 📝 Как протестировать реализованные функции

### 🎬 MOVIES.TSX

#### 1. **Тестирование Infinite Scroll**
1. Откройте страницу `/movies`
2. Выберите вкладку "Популярное Сейчас" или "Топ 1000 Всех Времён"
3. Прокрутите вниз до конца списка
4. **Ожидается**: Новые 20 фильмов должны автоматически загрузиться
5. **Визуальный индикатор**: Спиннер появится внизу страницы во время загрузки

#### 2. **Тестирование фильтра по категориям**
1. На странице Movies найдите блок "Категории" (Category Filter)
2. Кликните на одну из категорий: "Просмотрено", "Смотрю", "В планах", "Отложено", "Брошено"
3. **Ожидается**: Список фильмов должен обновиться (если у вас есть фильмы в этой категории)
4. Или выберите "Все" для отмены фильтра

#### 3. **Тестирование сортировки**
1. На странице Movies найдите dropdown "Сортировка"
2. Попробуйте разные варианты:
   - "По популярности" (по рангу для Top 1000)
   - "По рейтингу" (от 10 до 0)
   - "По названию" (A-Z)
   - "По году" (новые сначала)
3. **Ожидается**: Список должен переorderироваться в реальном времени

#### 4. **Тестирование фильтра по жанрам**
1. На странице Movies найдите dropdown "Жанр"
2. Выберите любой жанр
3. **Ожидается**: Список фильмов будет отфильтрован по выбранному жанру
4. ⚠️ Примечание: Жанровый фильтр требует полной интеграции с TMDB genre_ids

#### 5. **Тестирование комбинации фильтров**
1. Выберите категорию
2. Выберите сортировку
3. Выберите жанр
4. **Ожидается**: Все фильтры должны применяться вместе

#### 6. **Тестирование поиска с фильтрами**
1. Введите названием фильма в поле поиска (например, "Матрица")
2. **Ожидается**: Результаты поиска должны появиться
3. **Внимание**: Поиск переопределяет все остальные фильтры (по дизайну)

#### 7. **Тестирование ранга (Top 1000 вкладка)**
1. Откройте вкладку "Топ 1000 Всех Времён"
2. **Ожидается**: На каждом фильме вы должны увидеть желтый круг с ранком (#1, #2, и т.д.)
3. При наведении, ранг должен увеличиться (hover effect)

### 📺 SERIES.TSX

#### 1. **Тестирование Infinite Scroll для сериалов**
1. Откройте страницу `/series`
2. Прокрутите вниз до конца списка
3. **Ожидается**: Новые 20 сериалов должны автоматически загрузиться
4. Повторите несколько раз для проверки плавности

#### 2. **Тестирование фильтра по категориям сериалов**
1. На странице Series найдите блок категорий
2. Выберите категорию (если у вас есть сохранённые сериалы)
3. **Ожидается**: Список отфильтруется

#### 3. **Тестирование сортировки сериалов**
1. Используйте dropdown "Сортировка"
2. Попробуйте все варианты
3. **Ожидается**: Сериалы переorderируются

#### 4. **Тестирование поиска сериалов**
1. Введите названием сериала (например, "Breaking Bad")
2. **Ожидается**: Результаты должны появиться
3. Введите несуществующее названием
4. **Ожидается**: Сообщение "Нет результатов"

### 🎮 GAMES.TSX

#### 1. **Тестирование Infinite Scroll для игр**
1. Откройте страницу `/games`
2. Прокрутите вниз до конца списка
3. **Ожидается**: Новые 20 игр должны автоматически загрузиться
4. Спиннер должен показаться внизу страницы

#### 2. **Тестирование фильтра по жанрам игр**
1. На странице Games найдите кнопки жанров
2. Кликните на несколько жанров (например, "Action" и "RPG")
3. **Ожидается**: Список отфильтруется, показав только игры этих жанров
4. Кликните на жанр ещё раз для отмены выбора

#### 3. **Тестирование "Очистить фильтры"**
1. Установите фильтры (поиск + жанры)
2. Кликните на кнопку "Очистить фильтры"
3. **Ожидается**: Все фильтры должны очиститься, вернётся исходный список

#### 4. **Тестирование сортировки игр**
1. Используйте dropdown "Сортировка"
2. Выберите "По рейтингу"
3. **Ожидается**: Игры должны отсортироваться от самого высокого рейтинга к низкому

#### 5. **Тестирование поиска игр**
1. Введите названием игры (например, "Elden Ring")
2. **Ожидается**: Результаты должны появиться
3. Попробуйте поиск без фильтров и с фильтрами жанров

## 📱 МОБИЛЬНОЕ ТЕСТИРОВАНИЕ

### На мобильном устройстве или через DevTools:

1. **Откройте DevTools** (F12 или Cmd+Option+I)
2. **Включите Device Emulation** (Ctrl+Shift+M или Cmd+Shift+M)
3. Выберите iPhone 12 Pro или любой другой мобильный эмулятор
4. **Тестируйте**:
   - ✅ Grid должен быть 2 колонки (вместо 5 на desktop)
   - ✅ Фильтры должны быть вертикально расположены
   - ✅ Touch события работают (вместо hover)
   - ✅ Infinite scroll работает с touch прокруткой
   - ✅ Кнопки достаточно большие (44x44px)

## 🐛 ПОИСК ОШИБОК

### На что обратить внимание:

1. **Ошибки в консоли** (F12 → Console)
   - Должны быть только warnings о deprecated API
   - Не должно быть красных error сообщений

2. **Производительность** (F12 → Performance)
   - Загрузка фильтров должна быть < 5ms
   - Сортировка должна быть < 10ms
   - Нет lag при скролле

3. **Сетевые запросы** (F12 → Network)
   - TMDB API запросы для Movies/Series
   - RAWG API запросы для Games
   - Проверьте, что запросы успешны (200 OK)

4. **Storage** (F12 → Application)
   - Проверьте, что bookmarks сохраняются в Supabase
   - Проверьте localStorage если используется
